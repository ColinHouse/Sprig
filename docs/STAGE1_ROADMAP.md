# Stage-1 self-hosting roadmap

The current compiler is a Java seed. A small Sprig-written lexer/parser/evaluator
already runs in `tests/visitor/mini_pipeline.spr`; the recursive AST visitor in
`tests/visitor/ast_visitor.spr` exercises variants, recursion, and exhaustive
matching. These are feasibility slices, not a stage-1 compiler.

## Incremental path

1. **Freeze the seed contract.** Keep the current parser/type/runtime golden
   tests as the behavior oracle. Add a small corpus of source programs and
   expected diagnostics/output before changing semantics.
2. **Standard-library foundation.** Add and test UTF-8 file reading/writing,
   line/column tracking, predictable Unicode iteration, mutable builders,
   map/set utilities, and structured diagnostic construction. Keep filesystem
   and process APIs explicit.
3. **Lexer in Sprig.** Implement token kinds and source spans, then compare token
   streams against a reference fixture generated by the Java stage-0 path.
4. **Parser in Sprig.** Start with expressions and declarations, then indentation
   layout and recovery. Parse into Sprig variants; require exhaustive visitor
   matches so additions surface as compile errors.
5. **Stage-1 checker slice.** Add symbol tables and static types for the subset
   used by the stage-1 compiler itself. Emit stable diagnostics and preserve
   source ranges. Avoid `Any` escape hatches.
6. **Java backend slice.** Generate Java for the self-hosting subset and use
   stage-0 `sprig build` to compile the Sprig implementation. Compare stage-1
   token/AST/type/output fixtures with stage-0 and independent expected results.
7. **Bootstrap check.** Build stage-1 with stage-0, then use that output to
   rebuild stage-1. Compare normalized generated artifacts and run the same
   acceptance suite through both compilers before calling it self-hosting.

## Still missing for a practical compiler

The current small standard library has no compiler-grade source-file abstraction,
Unicode-aware scanner API, path/module discovery service, structured source map
builder, or complete collection helpers. Cross-file stage-1 compilation needs a
deliberate module API and deterministic build driver. The language can express
recursive functions, variants, visitors, collections, strings, and Java
generation templates, so these gaps are primarily library and engineering work;
the mini pipeline does not establish that a full compiler is already practical.
