# Archived Sprig v0.7 design kit

These documents preserve selected design goals and tool-protocol proposals
from the v0.7 design kit. They are historical material and may conflict with
the implementation. Do not use them as a language contract; consult the
current [`language reference`](../../language/) and compiler instead.

- [`language-spec.md`](LANGUAGE_SPEC.md) records the earlier language target.
- [`quick-reference.md`](QUICK_REFERENCE.md) preserves its compact examples.
- [`agent-friendly-decisions.md`](AGENT_FRIENDLY_DECISIONS.md) and
  [`agent-tool-protocol.md`](AGENT_TOOL_PROTOCOL.md) record earlier agent
  tooling choices and proposals.

The old design-kit contributor instructions and overview were consolidated
here. The obsolete short JVM interop design stub was removed because its
content is superseded by the longer historical proposal and current
[`JVM contract`](../../jvm/interop.md).
