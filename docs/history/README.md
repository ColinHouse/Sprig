# Historical evidence

This directory keeps selected design and engineering evidence that explains
how Sprig reached its current state. These files describe the checkout or
experiment named in each report; they are not current contracts or promises.

- [`milestones/`](milestones/) contains dated audits, dogfood reports and
  measured design experiments.
- [`design-kit/`](design-kit/README.md) contains selected v0.7 design documents
  retained for historical context.
- [`agent-evaluation/`](agent-evaluation/README.md) contains archived blind
  coding-agent trial artifacts, when present.

Current behavior lives in the compiler, runtime, grammar, tests and the
categorized pages linked from [`../README.md`](../README.md). Completed
implementation plans and superseded duplicate summaries are intentionally not
kept here; Git history preserves their revisions.
